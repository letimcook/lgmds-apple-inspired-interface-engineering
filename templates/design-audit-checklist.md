# Premium Interface Audit Checklist

- [ ] Existing correct structure preserved.
- [ ] Primary task visible within one glance.
- [ ] Spacing follows a repeatable rhythm.
- [ ] Shared axes and optical centers checked.
- [ ] Radii are coherent across nested surfaces.
- [ ] Glass is selective, not universal.
- [ ] Standard / Glassmorphism / Liquid Glass mode is explicit.
- [ ] Active state remains legible without animation.
- [ ] Motion has a named purpose.
- [ ] Persistent moving elements remain persistent objects.
- [ ] Sheets/popovers have clear dismissal behavior.
- [ ] Safe areas and system chrome considered.
- [ ] Light/dark and variable backgrounds tested.
- [ ] Reduce Motion checked.
- [ ] Accessibility semantics checked.
- [ ] Performance-sensitive effects profiled.
- [ ] Visual regression baseline captured where appropriate.
- [ ] External-source license/status checked.
