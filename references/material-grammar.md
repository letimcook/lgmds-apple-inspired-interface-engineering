# Material Grammar

| Property | Standard UI | Glassmorphism | Liquid Glass |
|---|---|---|---|
| Transparency | optional | core | core |
| Backdrop blur | optional | core | possible layer |
| Refraction/lensing | no | no | characteristic enhancement |
| Edge highlight | subtle | common | dynamic/specular |
| Morph between controls | not required | not required | important when related states merge/split |
| Touch deformation | minimal | optional | appropriate on interactive glass |
| Dense content surfaces | preferred | selective | generally avoid |
| Navigation/control layer | solid/native | possible | prime use case |

## Rule
Do not label a frosted card “Liquid Glass” unless the material also has a credible interaction/continuity model beyond static blur.
