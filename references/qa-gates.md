# QA Gates

## Static gate
- hierarchy obvious at rest;
- alignment axes consistent;
- no accidental overlap;
- selected state visible without motion;
- light/dark mode legible;
- safe-area clearances correct.

## Interaction gate
- pressed state begins immediately;
- no double-trigger or click-through;
- modal/popover dismisses predictably;
- focus does not become trapped;
- high-frequency controls remain fast.

## Motion gate
- one conceptual object remains one implementation object where continuity matters;
- no clipping during travel/morph;
- no hidden layout jump at settle;
- Reduce Motion has a designed fallback;
- motion stops in a visually correct final state.

## Brand gate
- final-frame overlay matches approved logo;
- source background is not accidentally embedded in the mark;
- color regions and negative space match;
- exported vector remains scalable.

## Source gate
- source exists and was verified;
- license is recorded;
- reference-only sources are not copied into production code;
- experimental code is explicitly marked experimental.
