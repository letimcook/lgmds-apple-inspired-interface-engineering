# Security Policy

LGMDS is a documentation-based Agent Skill (Markdown guidance, reference tables and small illustrative templates). It does not ship a runtime service, so most conventional security concerns do not apply directly.

If you find a security-relevant issue — for example, a template that encourages an unsafe pattern, or a misclassified license in `sources/SOURCE_REGISTRY.md` — please open a GitHub issue describing the problem. Do not include credentials, tokens or other secrets in issues or pull requests.
