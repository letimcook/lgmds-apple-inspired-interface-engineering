# Changelog

## 1.2.0 — 2026-09-23

### Added
- Packaged the repository as a Claude Code plugin (`.claude-plugin/plugin.json`).
- Added 11 `/lgmds-*` slash commands, one per `references/` module, so each topic can be invoked directly instead of only through natural-language routing.
- Documented the commands and their target modules in the README.

### Fixed
- Replaced the unresolved `OWNER` placeholder in the README install commands with the actual repository owner.

## 1.1.0 — 2026-09-22

### Changed
- Rebranded the master skill as **LGMDS — Apple-Inspired Interface Engineering**.
- Defined **LGMDS** as **Liquid Glass · Glassmorphism · Motion · Design · Systems**.
- Changed the canonical Agent Skill slug to `lgmds-apple-inspired-interface-engineering`.
- Added an explicit independence/trademark clarification: “Apple-Inspired” is descriptive and does not imply affiliation, sponsorship, endorsement, or official Apple status.
- Updated README, SKILL metadata, package identity, version and license attribution.

### Preserved
- Evidence-first source hierarchy.
- General-purpose scope beyond Apple platforms.
- Material distinction between Standard UI, Glassmorphism and Liquid Glass.
- Motion, navigation, logo-animation, SwiftUI, web, runtime, accessibility and QA modules.
- Source Registry and license-aware adoption policy.

## 1.0.0
- Initial modular Agent Skill release.
